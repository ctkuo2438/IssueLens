## 舊輸出的共同規則檢查

同一新函式辨識出：第一輪 #4032、留言補強輪的 #5804 與 #2948、PR 用途補強輪的 #4032，共四份案例回答中的矛盾。全部指向 `limitations[2]`。原始報告、原分數與人工狀態均保持不變。

這是對已知開發失敗的有限英文規則檢查，不是語意正確率。它沒有驗證所有推薦理由、數量表述、相反方向的矛盾或草稿時態。

## 用量、限制與仍待處理之處

模型與 GitHub 均為真實 API，同三筆案例各跑一次。共 20 次模型請求、16 次工具、96,980 個 API 回報 Token，40.01 秒。最大送出輸入估算 11,261；超標修正未送出。沒有摘錄省略，#4032 一次重讀目錄使用既有結果引用。

兩個驗證警告分屬不同問題：#5804 是原有引用檢查，#4032 才是新的一致性檢查。只有後者實際完成修正；兩案不能合併描述成兩次一致性修正成功。

#2948 草稿仍聲稱目前沒有該能力，卻沒有查目前程式碼或發布版本。原 PNG 標籤波動、其他語意與時態問題仍保持開放。#5804 未完成、#4032 仍有預算限制，本輪不能視為三案驗收全過或 M2 已完成。
