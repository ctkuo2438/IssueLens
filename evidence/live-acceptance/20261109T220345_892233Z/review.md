本輪原目錄中的 `python` 說明仍是 `Pull requests that update Python code`；標籤保留為來源證據，沒有從目錄刪除。三案都有被程式接受的最終 JSON。用途檢查通過不代表 `discussion`／`question` 等所有標籤理由已獲人工認可。

同一份新規則也辨識出第一輪 #5804，以及上一輪 #5804／#2948 的 PR 專用推薦。這是對保留輸出的另外檢查，原始報告、原評分及人工狀態均未改寫。

## 其餘品質仍待處理

#4032 的限制文字說沒有標籤推薦，清單卻列出兩項；本步未處理這種欄位一致性。其草稿已要求最小 Flask 重現，但這仍是一次模型判斷觀察。

#5804 草稿仍把歷史 #5812／3.2 計畫寫成未來安排，沒有驗證目前版本是否已修復，並再詢問回報者已提過的版本固定措施。這些時態與重複補問問題保持開放。

留言調查政策本輪仍取得 #5804 的 8 則及 #4032 的 2 則；#2948 依零留言 metadata 保持未查端點的狀態。`read` 是頁面覆蓋，不代表每則原文完整保存或語意使用正確。

## 檢查範圍

模型與 GitHub 都使用真實 API，各案只跑一次，沿用既有 `gpt-5.4-mini` 與預算。共 21 次模型請求、18 次工具、103,995 個 API 回報 Token，45.15 秒。最大送出輸入估算 11,158，低於 12,000 的原上限。

沒有輸入摘錄省略、相同結果重用或答案修正事件；本輪不能稱為已實際觀察後端拒絕 PR 標籤。該拒絕、有剩餘輪數的修正，以及耗盡預算的分支由模擬測試覆蓋。

有限英文用途規則仍可能漏判或誤判其他措辭。單次已知案例回歸不建立穩定性、標籤整體正確率或原 PNG 案的改善。原始資料與兩輪基準已核對雜湊未變，詳見[驗證紀錄](../../m2-label-scope-verification.json)。M2 尚未完成使用者人工驗收。
